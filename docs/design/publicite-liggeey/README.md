# Bannière publicitaire LIGGEEY (campagne d'exemple)

Sources des images `public/images/publicites/liggeey-large.jpg` (728 × 90) et `liggeey-mobile.jpg` (320 × 100).

Pour modifier la bannière : changer `large.html`, `mobile.html` ou `commun.css`, ouvrir le fichier dans Chrome,
puis faire une capture à la taille exacte, en x2 (1 456 × 180 et 640 × 200). Par exemple : outils de développement,
mode appareil, dimensions 728 × 90 (ou 320 × 100), facteur 2, puis « Capturer une capture d'écran ».
Enregistrer en JPEG (qualité 90), moins de 100 Ko.
