# Bannière publicitaire LIGGEEY (campagne d'exemple)

Sources des images `public/images/publicites/liggeey-970x250.jpg` (970 × 250) et `liggeey-320x200.jpg` (320 × 200).
Photo : `public/images/talents-hero.jpg` (Divaris Shirichena, Unsplash, provisoire, créditée dans `content/fr/legal.js`).

Pour modifier la bannière : changer `large.html`, `mobile.html` ou `commun.css`, ouvrir le fichier dans Chrome,
puis faire une capture à la taille exacte, en x2 (1 940 × 500 et 640 × 400). Par exemple : outils de développement,
mode appareil, dimensions 970 × 250 (ou 320 × 200), facteur 2, puis « Capturer une capture d'écran ».
Enregistrer en JPEG (qualité 85), moins de 200 Ko.
